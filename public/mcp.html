PERMISSIONS THAT ACTUALLY APPLY

These controls cover managed local wrappers only.

Website application grants do not authorize local files, terminal commands or MCP tools. Hosted Remote Desktop Commander and other unmanaged MCP servers retain their own permissions, quotas and sessions.

Codex/Claude built-in tools and separately connected hosted services are not controlled by this MCP policy.

Pause and read-only changes apply to new tool calls. They do not interrupt commands already running. This page offers no command box, file browser, credential export or remote shell.

Read-only allows a restricted tool set, not a security sandbox: writes, process launch, new searches and configuration tools are blocked. Paused instances can still initialize and list tools. Memory and disk admission checks apply to start_process, start_search, interact_with_process and write_pdf. Other safe reads do not require these resource checks.
